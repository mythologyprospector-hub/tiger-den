# Tiger Den

> **A map of the computational primitives humanity has already built.**

Tiger Den began with a simple idea: GitHub is an enormous box of code Legos, but much of what is inside has been independently reinvented thousands of times.

The project does **not** try to put all of those implementations in one repository.

**The world contains the code. Tiger Den contains the map.**

## Mission

Discover, identify, characterize, relate, and locate reusable computational primitives that already exist in the world's software.

The goal is to make the underlying computational landscape understandable and machine-readable without pretending that superficially similar implementations are identical or that one implementation must replace all others.

## Principles

- Evidence before assertion.
- Provenance is part of the result.
- Similarity does not prove equivalence.
- Meaningful differences must be preserved.
- Unknown is a valid result.
- The corpus determines the map.
- Discovery comes before synthesis.
- External code remains under its own licenses and governance.

## The Long View

If successful, Tiger Den will become an atlas of reusable computation: a place where an investigator can discover that a capability exists, understand what it does, see how it relates to other capabilities, inspect its evidence, and follow the map back to existing implementations.

Future composition or synthesis machinery may be useful, but it is downstream of the map and must be earned by evidence.
